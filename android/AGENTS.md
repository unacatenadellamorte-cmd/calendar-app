# 実機のアプリとデータを守るためのテスト制限

2026-09-26、掲載画像撮影時にconnectedDebugAndroidTestが接続中の実機まで対象にし、テストランナーの終了処理でjp.ryo.multicalendarがアンインストールされた。実機へ再インストールしたが、端末内データの完全復元は未確認。

- ユーザーの実機では、アプリをアンインストールするテストランナーを実行しない。
- connectedAndroidTest / connectedDebugAndroidTestなど、接続端末を一括対象にするタスクを撮影・検証に使わない。
- 撮影用はAPKをassembleでビルドし、adbの各コマンドで対象エミュレーターのシリアルを明示する。実行前にそのシリアルがエミュレーターであることを確認する。
- テスト内部の「エミュレーター専用」判定だけでは不十分。テストがスキップされてもランナー側のインストール・終了時アンインストールは実行される。
- ユーザーの実機へ更新する場合はシリアルを明示したinstall -rを使う。uninstall / pm clear / 自動初期化で解決しない。
- 一時ビルド環境を使う場合も本ルールを引き継ぐ。
