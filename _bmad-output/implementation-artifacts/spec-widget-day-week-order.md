## Intent
アプリのカレンダー並び順を全ウィジェットに反映し、週を月と同じ予定表示・テーマ・高速切替方式へ揃える。既存の「Multi calendar」ウィジェットは「日」に改称し、提示画像の左日付・右の色付き予定一覧へ変更する。
</frozen-after-approval>

## Implementation Notes
- 既存の受信クラスを維持して配置済みウィジェットを更新する。今日以降の予定を日付順、同日内はアプリの比較関数順に表示する。
- 非表示・シークレット予定の除外を維持する。日付・曜日・件名・時間とカレンダー色をテーマに合わせる。
- 月の共有データ監視と予定セルを週にも共有し、週移動は各ウィジェットの状態で管理する。
- 変更範囲はAndroidのウィジェットと共有データ、設定へのリンクおよび関連テスト。DB変更や公開は行わない。
- 開始時点 d94b3d6c6b4edfae72ff3919feb81233c63a3d6f。既存未追跡資料は維持する。

- アプリのcompareEventsForListへ順序を統一。以前のウィジェット独自規則は同順位内で終日を先にしていた。更新後は時刻付き→終日を含めアプリと一致する。
- 終了時刻を共有データへ追加し、排他的終了日と実際の終了日時を区別した。
- TypeScript関連43件、型検査、変更TSのESLint、Android単体30件、実描画3件成功。追加操作検証も成功し、日の設定・追加・予定タップで実Activityが正しいURLを受信することを確認。
- 800予定の月切替280〜355ms、週切替113〜275ms（エミュレータ実RemoteViews、予定到着とレイアウト確認を含む）。実機APK更新後、全3種表示、歯車→設定、予定→詳細を確認。
- 画像は共通出力画像フォルダの20260925_widget-day-week-device.png、20260925_widget-day-agenda.png、20260925_widget-week-unified.png。
