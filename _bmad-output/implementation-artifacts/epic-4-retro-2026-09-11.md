## 分析(Phase 2)

diff-scope レビューはインライン(narrowing: 独立モデルの反証なし)。挙動検証は本セッションの Phase C で全4ストーリーを実機実施(テンプレ作成 → quick-shift 3日一括 → pay-card ¥26,400 の内訳確認まで)。

### 集約ビュー: パターン乖離

**F1 ── `shift_templates` だけオフライン非対応(Epic 1 のオフラインファーストから外れている)** ── 重み: 低

- `src/data/shift-templates.ts:11` コメント:「オフライン対応(キャッシュ / outbox)は Story 4.1 では入れない(deferred)」。実装は `isNetworkError` → `data/offline` エラーを返すだけ。オフライン時はテンプレ一覧が「オフラインです」になり、作成・編集・削除もできない。
- Epic 1 は 1.3(カレンダー)/ 1.4(予定)もオンライン先行で作り、あとから 1.6 が `outbox.ts` / `cache.ts` / `sync.ts` で回収した。**shift_templates には対応する回収ストーリーが無い**。`local-db.ts` を DB v2 にして `shiftTemplates` ストアを足す作業が `deferred-work.md`(spec-4-1)に記載されているが、拾い手が未定。
- テンプレは低頻度データなので実害の優先度は低いが、「1エンティティだけオフライン非対応」は一貫性の穴。
- **disposition: defer(4.2 でオフライン quick-shift を触るときにまとめて回収 ── 追跡済み)**

**F2 ── 削除 Undo タイマの `clearTimeout` 漏れが `useEvents` / `useCalendars` に残る** ── 重み: 低

- `src/features/events/model/useEvents.ts:117` の `remove`: `const timer = setTimeout(finalize, UNDO_MS); pendingRef.current = { event, timer };` ── **直前に既存の `pendingRef.current.timer` を `clearTimeout` していない**(clearTimeout は unmount 用 `useEffect`(`:74`)だけ)。
- Undo 前に2件目を削除すると、1件目の孤児タイマが後で発火 → `finalize` が `pendingRef` を null にし `setPendingDelete(null)` → **2件目の Undo バーが早期に消える**。
- Story 4.1 は `useShiftTemplates`(`:93`)だけ `clearTimeout` を足して直し、他2フックは `deferred-work.md`(spec-4-1)へ記録 ── だが拾われていない。**同じ1行の修正が3フック中1つだけ適用済み**。
- 連続削除は稀だが、`useEvents` / `useCalendars` の `remove` に `pendingRef` 差し替え前の `clearTimeout` を1行ずつ足せば揃う。
- **disposition: fix-now(1行 × 2フック)**

### 集約ビュー: spec ⇔ 実装の突き合わせ

**F3 ── pay-card / pay-detail の丸め・月ラベルの既知の穴** ── 重み: 微

- `deferred-work.md`(spec-4-4)2件: (a) `PayDetailSheet` は行小計を per-row `Math.round`、カード合計は実額合算後に丸めるので、端数の出るシフトが複数あると「行小計の和」と「表示合計」が数円ずれうる。`monthlyPayEstimate` に `breakdown` を持たせて単一ソース化すれば消える。(b) pay-card の月ラベルは「9月」形式で年なし、12ヶ月送ると翌年同月と区別不可。
- 個人の時給は通常キリの良い数字 / そこまで月送りする利用は稀。
- **disposition: defer(追跡済み)**

**F4 ── quick-shift の範囲選択・週からの導線・シフトのオフライン作成が未実装** ── 重み: 微

- `deferred-work.md`(spec-4-2): 月グリッドのドラッグ範囲選択(ステッパ 1〜14 で代替済み)、週ビューの日タップから quick-shift(週はスロット = 時刻指定のまま)、`createShifts` の outbox 対応。
- モバイル web のグリッドドラッグは scroll と競合(Epic 1/2 の同種判断と一貫)。ステッパで「1週間分」の主目的は満たせている(Phase C で3日一括を確認)。
- **disposition: defer(追跡済み)**

**minor ── 無効入力後のバリデーションエラーバナーが画面レベルで残る** ── 重み: 微

- Phase C で観測: `ShiftTemplateFormSheet` で休憩 ≥ 実働の無効入力 → エラー → 修正して別のテンプレを正常作成 → 画面上部に前のエラーバナー「休憩は0以上で…」+「閉じる」が残っていた(「閉じる」で消える)。成功後にクリアされるべき。
- **disposition: fix-now(小)**

### 証拠が裏付ける改善(維持すべき点)
