## Intent

初回プロフィールと既存プロフィールに言語選択を追加。ユーザー指定の日本語・英語・中国語簡体字・韓国語・スペイン語・フランス語を対応する。アプリの操作文言・エラー・カレンダー日付表示を切り替える。

## Boundaries & Constraints

ユーザー作成の名前・予定件名・メモ・カレンダー名は翻訳しない。言語設定は表示設定としてこの端末へ保存し、即時反映。初回は端末言語から候補を選び、非対応なら英語。保存失敗を表示する。既存の予定・プロフィールDBや通貨単位・タイムゾーンは変更しない。

## Code Map

- src/i18n/: 言語ストア、翻訳辞書、差し込み、選択UI。
- src/features/profile/ui/ProfileForm.tsx: 初回・編集共通の言語選択。
- src/app/、src/features/、src/ui/: 固定操作文言の辞書参照と変更購読。
- src/lib/datetime.ts、money.ts: Intl表示。日付キーや計算は維持。
- src/data/messages.ts: エラーの表示時に翻訳。

## Implementation Notes

ユーザーの更新された実行方針に従い、低コストモデルgpt-5.6-lunaの3サブエージェントが翻訳辞書を担当。メインが設計・実装・統合・最終検証、1サブエージェントが読取専用の局所監査を担当。外部翻訳サービスへユーザーデータを送信しない。日本語を元の文言キーとし、固定文言のみを明示的に翻訳する。
