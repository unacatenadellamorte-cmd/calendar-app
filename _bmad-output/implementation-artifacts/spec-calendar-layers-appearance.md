## Intent

予定入力から戻るとホームへ遷移する問題を直し、入力レイヤーを下へスライドしてカレンダーへ戻せるようにする。シフト操作を左上へ移し、中央揃えの「← 削除 →」とする。背景画像と複数の配色を設定から選択できるようにする。

## Boundaries & Constraints

既存の予定保存処理、秘密予定の保護、選択日を維持する。Androidの戻る操作では最前面のレイヤーを閉じる。背景は端末内に保存し、外部へ送信しない。既存の明暗テーマを保持し、新しい配色は共通トークンで管理する。DBの移行や本人の予定を変更する検証は行わない。

## Code Map

- `src/ui/BottomSheet.tsx`: 共通レイヤー。現在はEscapeと背景押下だけ対応。スクロール、下スワイプ、Android戻る対応を追加。
- `src/features/calendar/ui/CalendarScreen.tsx`: 入力フォームを閉じる際に折りたたみも解除。
- `src/features/calendar/ui/MonthShiftTiles.tsx`: 左寄せの操作領域。各ボタン中央揃え、矢印は横長。
- `src/features/settings/model/useTheme.ts`、`src/styles/tokens.css`: 既存のテーマ保存・CSS変数を拡張。
- `src/features/settings/ui/SettingsScreen.tsx`: 配色見本と背景選択・解除を追加。
- `src/ui/Screen.tsx`、`src/main.tsx`: 保存済み背景を起動時に復元し、透過した画面背景の下へ表示。
