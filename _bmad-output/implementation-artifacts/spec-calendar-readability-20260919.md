## Intent

ユーザーが指摘した6点をまとめて修正する。月表示の件名を約5文字読める小さい文字にし、長い件名を横へ流す。取り込み・並び替え・プロフィールを含め全画面でステータスバーとの重なりを防ぐ。背景画像設定時はカレンダー等の面を約40%透過する。Google取り込み中の表示を「同期中」にする。Android週ウィジェットを日付タップ後の横長7列週表示に合わせる。月下のお気に入りシフト長押しで対象の編集を開く。

## Boundaries & Constraints

通常タップのシフト追加、日付タップ・長押し・ダブルタップ、秘密予定の除外、ウィジェットからの日付指定追加を維持。文字自体は透過しない。動きを減らす端末設定を尊重。実際の通信失敗を永続的な「同期中」で隠さない。対象はローカル修正と検証。既存の未追跡成果物は保持し公開しない。

## I/O & Edge-Case Matrix

| 状態・操作 | 期待 |
|---|---|
| 短い月予定件名 | 小さい文字で静止表示 |
| 表示幅を超える件名 | 横移動で末尾まで読める |
| 背景画像あり・なし | ありの場合だけ面を透過 |
| ステータスバーと画面スクロール | 見出し・操作がバーと重ならない |
| Google取り込み中・完了・失敗 | 進行中は「同期中」、完了で解除、失敗は失敗として表示 |
| シフト短押し・長押し | 短押しは追加、長押しは編集のみ |
| 長押し中の移動・キャンセル | 編集と追加の誤発火を防止 |
| 週ウィジェット | 日〜土の横7列で日付と予定を表示、日付指定追加を維持 |
