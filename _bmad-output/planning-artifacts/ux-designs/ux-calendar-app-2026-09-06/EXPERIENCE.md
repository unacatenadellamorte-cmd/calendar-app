# カレンダーアプリ(仮) — Experience Spine

> v1 は Web アプリ(スマホブラウザ最適化 + PWA)。ペア: `DESIGN.md`。PRD の用語(カレンダー / 予定 / 外部接続 / 取り込み / 優先度 / 代表予定 / コンパクトビュー / お気に入りシフト / シフト / 実働時間 / 給料見込み)をそのまま使う。

## Foundation

- **フォームファクタ:** v1 は Web、スマホ縦が基準。レスポンシブでタブレット/PC 幅に広がる。PWA としてホーム画面にインストール可。
- **UI システム:** 指定なし。ブラウザ標準の挙動(スクロール、フォーカス、テキスト選択、文字サイズ設定)を尊重する。 `[ASSUMPTION: 実装スタックは addendum の第一候補(Next.js + Tailwind)だが、この Spine はスタック非依存。]`
- **テーマ:** 端末設定に追従(light / dark 両対応)。設定で固定も可。 `[ASSUMPTION: ダークモード方針は無回答のため「端末追従」で仮置き。]`
- `DESIGN.md` が視覚の唯一の参照。矛盾したら Spine が勝つ。
- **将来のネイティブ展開(v1.5/v2):** ウィジェット・リマインダー通知・端末カレンダー取り込み。コンパクトビューの選抜結果(§優先度と選抜の挙動)は1か所で計算し、アプリ内画面・ウィジェット・通知が同じ結果を共有できる形にしておく。

## 優先度と選抜の挙動(製品固有)

このアプリの中核。PRD FR-6〜FR-10 の挙動をまとめる。

- **優先度の設定 = 並べ替え。** カレンダー管理画面で行をドラッグして順位を変える。数値入力や重み設定はしない。順位は全カレンダーで一意。新しく追加・取り込まれたカレンダーは最下位に入る。
- **並び順への作用(FR-8):** カレンダー一覧、リストビュー、コンパクトビュー、月セル内の予定の積み順、週タイムラインの重なり順 ── すべて優先度順。同順位内は開始時刻順。優先度を変えると再読み込みなしで即反映。
- **視覚的な優先(FR-7):** 週ビューで時間が重なる予定は、優先度が高いカレンダーのものを左端/前面に。月ビューでセルに入りきらない時は優先度が高い予定から見せ、あふれを「他 N 件」に畳む。
- **代表予定の選抜(FR-9)= コンパクトビューの中身:**
  1. 現在時刻以降に始まる / 進行中の予定だけが対象。過去は出さない。
  2. 優先度が高いカレンダーの予定を、低いカレンダーの予定より先に。
  3. 同じカレンダー内は開始時刻順。
  4. 終日予定は時刻付き予定をすべて出した後に回す。
  5. 表示件数(既定3、設定で1〜3)に達したら打ち切り。
  - `[ASSUMPTION: 全体規則は「優先度 → 開始時刻順」。対案「優先度 → 今から近い順」は PRD §9-1 の未解決論点。Spine は現行案で書く。]`
- **一貫性:** アプリ内コンパクトビュー画面・(将来の)ウィジェット・通知は、この選抜を同じ入力で呼べば同じ結果を返す。

## Voice and Tone

マイクロコピー。ブランドの声・美的姿勢は `DESIGN.md.Brand & Style`。

- 日本語、簡潔、丁寧すぎない。時刻や件名は体言止め。文末に感嘆符を置かない。
- 専門語を避ける:「OAuth」ではなく「Googleと接続」、「同期」より「取り込み」。

| Do | Don't |
|---|---|
| 「この後の予定はありません」 | 「予定なし！ ゆっくり休んで」 |
| 「10:00 役員会議」 | 「まもなく: 役員会議です」 |
| 「Googleカレンダーを接続」 | 「アカウント連携をセットアップ」 |
| 「取り込めませんでした。再試行」 | 「同期エラー (code 502)」 |
| 「このシフトを削除しますか」 | 「本当によろしいですか?」 |
| 「今月の見込み ¥53,900」 | 「あなたは頑張りました! 見込み ¥53,900」 |

## Component Patterns

挙動。視覚仕様は `DESIGN.md.Components`。

| コンポーネント | 使う場所 | 挙動ルール |
|---|---|---|
| compact-card | ホーム | 代表予定を優先度順に最大3件。予定タップ → カレンダーの該当日へ。手動更新は引っ張り更新。 |
| month-cell | カレンダー(月) | タップ → その日(週ビュー)へ。長押し or セルの + → quick-shift-sheet。「他 N 件」タップ → その日の全予定を優先度順で一覧。 |
| week-timeline | カレンダー(週) | 空きスロットをタップ → 予定を追加(その時刻がプリセット)。予定タップ → 予定の詳細。 |
| event-chip | 月 / 週 / リスト / コンパクト | タップ → 詳細。取り込み予定は詳細を開いても編集ボタンを出さない。 |
| calendar-row | カレンダー管理 | ドラッグ(またはキーボードの「上へ/下へ」)で優先度変更。トグルで表示オン/オフ(オフでも優先度は保持)。行タップ → 改名・色・接続解除。 |
| shift-template-chip | quick-shift-sheet / お気に入りシフト管理 | シートでタップ → その日にシフト作成しシートを閉じる。管理画面でタップ → テンプレ編集。 |
| pay-card | ホーム | タップ → 給料見込みの詳細。矢印で前月/翌月。シフトの追加・編集・削除で即再計算。 |
| quick-shift-sheet | 月/週で日付選択時 | 登録済みテンプレを横スクロール。テンプレなしなら「お気に入りシフトを作る」を促す。「予定を追加」タブへ切替可。 |
| connection-card | カレンダー管理 / 設定 | 未接続: 「接続」ボタン。接続済み: 最終取り込み時刻、失敗時は該当カレンダー行に警告 + 再試行、「今すぐ取り込み」、解除。 |

## State Patterns

| 状態 | サーフェス | 扱い |
|---|---|---|
| 初回起動・データなし | ホーム | 「まだ予定がありません」+「カレンダーを接続」「予定を追加」の2つの入口。 |
| この後の予定なし | ホーム compact-card | 「この後の予定はありません」1行。給料見込みカードは通常表示。 |
| カレンダー未接続 | ホーム / カレンダー管理 | connection-card で「Googleカレンダーを接続」。ローカル予定は普通に使える。 |
| 取り込み中 | カレンダー管理 | 対象カレンダー行に控えめなスピナー。他カレンダーの表示は止めない。 |
| 取り込み失敗 | カレンダー管理 | 該当行に「取り込めませんでした・再試行」。ホーム/カレンダーは最後に取り込めた内容を出し続ける。 |
| オフライン(PWA) | 全体 | ローカルのデータは通常表示。取り込みは走らせず、カレンダー管理に「オフライン」表示。オンライン復帰で自動取り込み。 |
| 未ログインで Google 接続 | 接続フロー | ログイン/アカウント作成へ誘導 → 完了後に接続フローへ戻る。 |
| お気に入りシフト未登録で日付タップ | quick-shift-sheet | 「よく使うシフトを登録すると1タップで入れられます」+ 作成ボタン。 |
| 給料見込み ¥0 | ホーム / 詳細 | 「今月のシフトはまだありません」。 |
| 破壊的操作(カレンダー削除 / 接続解除 / シフト削除) | 確認シート | 影響を明示(「接続を解除すると、このアカウントから取り込んだ予定は消えます」)。削除後は一定時間 Undo を提示。 |
| フォーカス | 全入力・ボタン | ブラウザ標準のフォーカスリング(`DESIGN.md` accent)。消さない。 |

## Interaction Primitives

- タップで開く / 実行する。長押しは「その日にすばやく追加」だけに割り当てる(システムのテキスト選択と競合しない要素に限る)。
- **優先度の並べ替え:** ドラッグが主。**必ずキーボード/ボタンの代替**(行にフォーカス →「上へ / 下へ」)を用意する。
- 月ビューは横スワイプで前月/翌月。週ビューは横スワイプで前日/翌日。
- 引っ張って更新はホームとカレンダーのみ。
- リスト行のスワイプ削除(確認付き)。
- **やらないこと:** カルーセル、起動時のヒーローアニメ、バッジカウント、ストリーク、再エンゲージのプッシュ通知、パララックス。

## Accessibility Floor

挙動。視覚コントラストは `DESIGN.md`。

- **色に意味を依存させない。** 予定は必ず「カレンダー色バー + カレンダー名(または頭文字)」をセットで示す。優先度は順位番号でも表す。
- **並べ替えのキーボード操作:** ドラッグ以外に「上へ/下へ」操作を必ず提供。スクリーンリーダーは「優先度 2/5、上へ移動可能」のように現在地と操作を読む。
- スクリーンリーダー: すべての操作要素に役割 + 状態のラベル。コンパクトビューの読み上げ順 = 優先度順。取り込み中/失敗は該当カレンダー名とともに読み上げる。
- 文字サイズ: `DESIGN.md` のタイポトークン経由でブラウザ設定を尊重。最大設定でもコントロールが切れない。
- Reduce Motion: シートやビュー切替のトランジションを省略、状態は即時に反映。
- タップターゲット 44px 以上。フォーカス移動は各サーフェスの読み順に従う。
- コントラスト AA(通常テキスト 4.5:1、大きいテキスト 3:1)。

## Inspiration & Anti-patterns

- **シフカレから採る:** お気に入りシフト → 日付タップ → テンプレ選択、の最小手数入力(quick-shift-sheet)。給料見込みが入力に連動して増える即時フィードバック。
- **Googleカレンダーから採る:** 月/週の標準レイアウト、色での識別、素直な前後スワイプ。奇をてらわない。
- **却下 ── 優先度の効き方を設定で刻ませる:** PRD SM-C1。順位ひとつに絞ることが手軽さの核。刻める版は「柔軟に見えて実際は誰も設定しない」。
- **却下 ── v1 で割増・締め日の給料設定:** PRD SM-C2。v1 は時給 ×(終了−開始−休憩)の暦月合計だけ。
- **却下 ── ストリーク / 再エンゲージ通知:** カレンダーは予定を映す道具。使わなかった日を責めない。
- **却下 ── 独自のカレンダー表現(円形タイムライン等):** 「見やすさ」を参照点に置いた以上、学習コストのある表現は入れない。

## Responsive & Platform

- **スマホ縦(基準):** 単一カラム。下タブ3つ。月ビューは7列で縦スクロール。週ビューは1日タイムライン。
- **タブレット / PC 幅:** 月ビューを広く使い、右側に選択日の予定リストを添える2カラムも可(v1 では単純化してよい)。 `[ASSUMPTION: 広幅の2カラムは v1 では任意。まずスマホ幅を完成させる。]`
- **PWA:** ホーム画面インストール、スプラッシュ、オフラインでローカルデータ閲覧。
- **将来(Capacitor 等でネイティブ化):** ホーム画面ウィジェット = コンパクトビューの縮小版(1/2/3件)。リマインダー通知 = 選抜結果の先頭。端末カレンダー取り込み = 外部接続の追加種別。いずれも本 Spine の挙動を継承し、視覚は `DESIGN.md` トークンで。

## Key Flows

### Flow 1 — 圭太、家を出る前(UJ-1)

1. 圭太がアプリ(PWA アイコン)を開く。前回セッションで認証済み。
2. ホームが開き、compact-card の先頭に「10:00 役員会議」(優先度最上位「仕事」カレンダー)。
3. その下に次点2件。部活の連絡予定は「他」に畳まれ、見えていない。
4. 給料見込みカードは今月分を静かに表示。
5. **クライマックス:** 圭太は1秒で「今日いちばん外せないのは役員会議」と分かる。他の予定に埋もれていない。
6. アプリを閉じて家を出る。
- 失敗時: 直近の取り込みが失敗 → compact-card は最後に取れた予定を表示し続け、カレンダー管理にだけ「取り込めませんでした」。

### Flow 2 — 圭太、初回セットアップ(UJ-2)

1. ホームの「カレンダーを接続」→ connection-card →「Google」。
2. (未ログインなら)アカウント作成 → 接続フローに戻る。
3. Google 認可(読み取りのみ)→ アカウント内の「個人 / 仕事 / 部活」から取り込む3つを選択。
4. カレンダー管理に3行が並ぶ(既定は最下位の優先度)。
5. 行をドラッグして「仕事 > 個人 > 部活」に並べ替え。
6. **クライマックス:** ホームに戻ると compact-card の先頭が「仕事」カレンダーの予定に変わっている。月ビューでも重なりが優先度順に描かれる。
- 以降、取り込みは自動。キーボードのみでも「上へ/下へ」で並べ替えできる。

### Flow 3 — 美咲、1週間のシフト入力(UJ-3)

1. 事前に「平日シフト(17:00–22:00 休憩30分 時給1,100)」「土曜シフト(9:00–18:00 休憩60分 時給1,100)」をお気に入りシフトに登録済み。
2. カレンダー(月)で平日の日付をタップ → quick-shift-sheet が下から出る。
3. 「平日シフト」チップをタップ → その日にシフトが入り、シートが閉じる。これを5日分繰り返す(連続日ならまとめて選択して一括適用)。
4. 土曜をタップ →「土曜シフト」を選択。
5. **クライマックス:** ホームの給料見込みカードが入力のたびに増える。シフトはカレンダーにも「シフト用カレンダー」の予定として並ぶ。
6. 見込みカードをタップ → 今月のシフト内訳を確認。
- 空状態: テンプレ未登録で日付をタップ → シートが「お気に入りシフトを作る」を促す。
- エッジ: 深夜0時をまたぐシフトも1勤務として実働時間を通算(FR-13)。
