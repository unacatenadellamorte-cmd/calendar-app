# シフトから追加する予定のラベル色（2026-09-29）

ユーザーがシフトの選択色と予定ラベル色の不一致を指摘し、シフト色の継承と選択色の拡充を依頼した。

## 原因と修正
`createShifts` がシフトの色を挿入行へ書かず、取得列と返却予定にも色を含めていなかった。`label_color` を保存・取得し `labelColor` として返すよう修正。月画面の登録シフトとシフト追加画面は同じ関数を使うため両方に適用される。既存の予定ラベル描画・ウィジェット連携を経由する。

シフト設定を共通24色プリセットに統一。前回の配列拡張で増えた色を使い、選択チェック、小文字保存色の一致、色名の翻訳を共通化。

## 適用範囲
更新版で新しくシフトから追加する予定に、追加時点のシフト色が入る。既存予定への一括上書きや、テンプレ色変更時の遡及反映は行わない。過去の予定は個別編集でラベル色を変更できる。個別色とカレンダー色へ戻す操作は維持する。

## 検証
修正前は追加した色継承テストが失敗することを確認。修正後は保存値・取得列・返却値・キャッシュ・再取得を確認。関連4ファイル93テスト、型検査、Webビルド、変更ファイルのlintが成功。実データ変更・端末更新・Play公開は実施していない。

レビューでは実装の不具合指摘なし、検証不足2点を補強。再取得時のSELECTにもlabel_colorが含まれることと、24色全てがシフトの保存バリデーションを通ることを追加確認。補強後の関連3ファイル32テストと型検査・lint成功。
