# カレンダー不備２の対応

ユーザー指定の `カレンダー不備２.txt` に記載された8項目を修正。

- 月ウィジェット: 1件固定を廃止。セル高・文字倍率に応じて複数予定を描画し、超過数は日付行に表示。
- 週ウィジェット: 各日付の＋を削除。ヘッダーの追加ボタンは維持。
- ホーム・カレンダー・設定: プロフィールアイコンをステータスバー直下の見出し行に集約。カレンダーは「＋シフト」「＋予定」、ホームは並び順操作を同じ行へ。他画面名とプロフィールのダブルタップ操作を維持。
- 背景: 2本指のピンチで倍率1〜3を調整。テーマ色と半透明の架空月カレンダーを重ねて確認可能。モックは画像へ保存しない。
- 月予定文字: 小8px（従来サイズ）・中10px・大12px。設定を端末保存し、長い件名のスクロールを維持。
- リスト: 表示切替と日付操作を画面内に残し、予定領域だけスクロール。月への復帰時にページ全体が過去のスクロール位置へ飛ばない。
- カレンダー本文の左右余白を8pxへ縮小。
- 地図: 自作予定を再度開くと編集画面へ進む一方、前回の起動ボタンが取り込み予定の詳細画面だけに存在していた。編集画面にも「地図を開く」「リンクを開く」を追加し、起動失敗を画面内に表示。起動操作による意図しない保存は行わない。
