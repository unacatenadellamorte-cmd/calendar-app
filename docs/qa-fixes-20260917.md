# QA指摘への対応（2026-09-17）

対象: QAレポート20260917。Androidテスト版1.0.10 / versionCode 11。

| 番号 | 対応・確認結果 |
| --- | --- |
| 1 | 外部カレンダーを予定の作成・移動先から除外。データ層でも外部・不明な所属先を拒否。過去に誤登録されたlocal予定は自作カレンダーへ移動可能。 |
| 2 | 通知プリセットを即時選択表示。Androidでは許可結果後に1回保存し、連打を抑制。Webの通知非対応を明示し、設定値は保存。 |
| 3 | Webの戻る操作でも入力レイヤー→週一覧→月カレンダーの順に戻す。同URLの履歴ガードを追加。 |
| 4 | 初回タップで週へ折りたたまれた直後も、同じ位置の2回目タップを元の日付のダブルタップとして処理。 |
| 5 | プロフィール空欄時の入力エラーと保存完了の表示を追加。 |
| 6 | カレンダーフォームの初期化を編集単位に限定。表示切替をIDごとに直列保存し、古い再取得応答による巻戻りを防止。テーマ自体の初回クリック不反映は単独で再現していない。 |
| 7 | シフトフォームも編集単位で初期化し、再取得で入力済みの名前・休憩・時給が消える問題を修正。 |
| 8 | 削除・編集中の古い一覧取得結果を適用しない。削除IDを保護し、削除失敗時は該当予定だけ復元。並行追加や別予定の削除は維持。 |
| 9 | 現行コードでは折りたたみ週も秘密予定を除外済み。ロック中に件名が表示されない回帰テストを追加。今回の確認では再現なし。 |
| 10 | 現行コードは4〜8文字の半角英数字を検証し入力欄も8文字上限。既存検証を確認。9文字保存は再現なし。 |
| 11 | カレンダー色の選択済み状態にチェックマークを追加。 |
| 12 | 設定リンクを遷移先と同じ「カレンダーの並び順」に統一。 |
| 13 | 背景画像エラーを次の画像選択で消去し、閉じる操作を追加。 |
| 14 | 給料カードに「概算・目安」を追加。 |
| 15 | パスコード入力を修正した時点で直前のエラーを解除。 |
| 16 | 日時が空欄・不正な場合、UTC変換前に検証し画面内エラーとして処理。ブラウザ標準の日時入力部品の区切り入力方式は維持。 |
| 17 | 今後の予定がない場合も一覧末尾の直近予定へスクロールし、最古の予定で止まらないよう修正。 |
