# 1.0.19（20）の広告・入力操作改善（2026-09-29）

## 依頼と実装方針

ユーザーは広告をカレンダー表示切替（年・月・日・リスト）と年月見出しの間へ移動し、アダプティブバナー・30秒更新にしてクローズドテストへ更新するよう依頼。追加で、ウィジェットの日付タップによるカレンダー起動、シフト登録後の翌日移動設定を依頼した。

Android標準ウィジェットの長押しは予定追加へ割り当てられない制約を説明し、ユーザーは既存の「＋」からの追加を選択した。月・週の日付セルと日ウィジェットの日付領域は日付リンクへ変更。「＋」は作成リンクを維持。同じ日付を開き直す場合も入力シート・以前の表示モードを持ち越さない。

シフトの翌日移動は既定OFF。設定に従い、登録成功時だけ次の暦日へ移動。登録中の日付変更・アンマウントでは古い応答による移動を避ける。
