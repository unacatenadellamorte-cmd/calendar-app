# 予定の場所・URLと背景表示の改善

## 変更

- 予定の新規作成・編集に場所と予定URLを追加。詳細から場所を地図、URLを外部アプリへ渡す。URLはHTTP/HTTPSのみ許可する。
- 設定でGoogle Maps、Apple Maps、標準地図を選択。設定は端末内に保存する。ZoomのHTTPS会議リンクもOSへ渡すが、開くアプリは端末の関連付けに依存する。
- `events.location` と `events.event_url` をnullableで追加。既存予定を維持し、オフライン保存・再送・JSON書き出しにも対応。旧patchのキー省略では既存値を消さない。
- 背景画像はホームとカレンダーに限定。選択後に移動・拡大してトリミングし、確定後にだけ保存。JPEG/PNG/WebP・20MB制限と再エンコードを維持。
- プレビューと保存の切り出し計算を共通化。保存中のシート閉鎖と範囲変更を抑止し、キャンセル・読込失敗・保存失敗から復帰できる。
- 年/月/日/リスト切替、日付移動、シフト操作、見出し・説明を濃色面で表示。下部タブと端末ステータスバーを不透明にし、テーマ色と白いアイコンを合わせる。月セルは背景ありで約40%透過を維持。
- 5言語の辞書を更新。Androidは1.0.13（versionCode 14）。Android/iOSへAppLauncherを登録。
