# 表示とシフト操作の修正（2026-09-19）

対象はAndroidテスト版1.0.12 / versionCode 13。

- 月カレンダーの件名を8px・狭い余白へ変更。360px幅では約5文字が入り、はみ出す件名だけ実幅に合わせて横移動する。短い件名は静止。動きを減らす設定では停止し、日付タップ後の一覧で全文を読める。
- Capacitor 8が注入する `--safe-area-inset-top` を画面上端で使用。CSSの `env()` だけでは取得できなかったAndroidのステータスバー領域を避ける。下部タブとシートも下端の変数を使用。独自のネイティブ余白処理は追加しない。
- 背景画像設定時にカレンダー面を60%不透明（40%透過）へ変更。画面全体と月予定チップは透明にし、面の重ね合わせで写真が隠れる問題を防ぐ。背景未設定時は従来の面色を維持。
- Google取り込み中は「同期中」を表示し、前回の結果・接続エラーを同時表示しない。カレンダー一覧更新中の表示も統一。実際の通信失敗は完了後にエラーとして表示し、同期中と偽らない。
- Android週ウィジェットを日〜土の横7列へ変更。日付・件名・追加操作を配置し、最小高さを見直す。秘密予定除外などの共有処理は維持。
- 月表示下のお気に入りシフトは500ms長押しでそのテンプレート編集を開く。通常タップは選択日への追加。長押し後のクリック、移動・右クリック・中断による誤動作を抑止する。

## 確認結果

- 全111テストファイル・925件成功。型検査、src/packagesのESLint成功。
- ブラウザで320/360/390px枠の実コンポーネントを表示。短い件名の静止と長い件名の横移動を確認。
- 背景設定時の計測値: 月セルの不透明度0.6、予定チップ・画面全体は透明。目視でも背景が見えることを確認。
- 低コストモデル3担当で実装・デバッグ。メインが差分と実表示を確認し、追加の独立レビューでは指摘なし。
- 実サービスへのGoogle再取り込みやデータ登録は今回のブラウザ検証では実施しない。検証用ページは削除済み。
